## Questão Discursiva 2 

> Uma aplicação Django REST está em produção no Elastic Beanstalk há 6 meses. Recentemente, a equipe começou a enfrentar os seguintes problemas:

- Problema 1: Após cada deploy, o sistema fica indisponível por aproximadamente 30 segundos, causando timeout em requisições de clientes.

- Problema 2: Usuários relatam que, ocasionalmente, ao fazer upload de imagens de perfil, a imagem não aparece após o upload ou aparece corrompida. Isso acontece em cerca de 5% dos uploads.

- Problema 3: O tempo de resposta da aplicação aumentou significativamente nos horários de pico (das 18h às 22h), com algumas requisições demorando mais de 5 segundos.

- Problema 4: O desenvolvedor precisa acessar logs detalhados para investigar os problemas, mas o comando eb logs retorna apenas logs limitados.

Perguntas:

a) Para o Problema 1 (indisponibilidade pós-deploy), qual é a causa mais provável e como resolvê-la utilizando configuração do Elastic Beanstalk?

b) Para o Problema 2 (uploads de imagem inconsistentes), considerando que as imagens são salvas no sistema de arquivos local, qual é a causa raiz? Proponha uma solução definitiva utilizando S3 com django-storages.

c) Para o Problema 3 (performance degradada em horário de pico), proponha duas estratégias de escalabilidade que podem ser configuradas no Elastic Beanstalk para resolver o problema.

d) Para o Problema 4 (logs limitados), explique como habilitar o streaming de logs para o Amazon CloudWatch Logs no Elastic Beanstalk e como acessar logs detalhados da aplicação Django (incluindo logs customizados com o logging do Django).

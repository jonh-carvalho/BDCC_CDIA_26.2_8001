    Avaliação Continuada 02¶

    👉 Formulário de AC2¶

    Questão 1 (ENADE)¶

    Uma empresa de desenvolvimento de software precisa hospedar uma aplicação web legada que roda em um servidor Windows com configurações específicas de IIS e dependências de sistema. A equipe de TI tem experiência em administração de servidores e deseja ter controle total sobre o ambiente.

    Qual modelo de serviço em nuvem é mais adequado?

    a) IaaS, pois permite configurar o sistema operacional e todas as dependências.

    b) PaaS, pois a plataforma gerencia automaticamente o ambiente.

    c) SaaS, pois a aplicação seria fornecida como serviço.

    d) Serverless, pois elimina a necessidade de servidores.

    e) Nuvem híbrida, pois combina modelos públicos e privados.

    Questão 2¶

    Uma startup deseja lançar um MVP (Minimum Viable Product) de uma aplicação web em Python. A equipe é pequena e não tem especialistas em infraestrutura. O objetivo é colocar o produto no ar rapidamente e com baixo custo inicial.

    Qual serviço AWS é mais indicado?

    a) Amazon EC2, para ter controle total.

    b) AWS Elastic Beanstalk, para deploy rápido e gerenciado.

    c) Amazon WorkSpaces, para desktops virtuais.

    d) Amazon S3, para hospedar site estático.

    e) AWS Lambda, para funções serverless.

    Questão 3¶

    Analise as afirmativas sobre modelos de serviço em nuvem:

    I. No modelo IaaS, o provedor é responsável pela segurança física e virtualização, enquanto o cliente gerencia o sistema operacional e aplicações.

    II. No modelo PaaS, o cliente não precisa se preocupar com patches do sistema operacional, pois o provedor os gerencia.

    III. No modelo SaaS, o cliente tem controle total sobre o ambiente de execução e pode instalar qualquer software.

    Está correto o que se afirma em:

    a) I, apenas

    b) II, apenas

    c) I e II, apenas

    d) I e III, apenas

    e) I, II e III

    Questão 4¶

    Uma empresa quer migrar seu CRM para a nuvem. O CRM é um software de mercado, como Salesforce, e a empresa não quer se preocupar com servidores, atualizações ou backups.

    Qual modelo de serviço atende a essa necessidade?

    a) IaaS, pois podem instalar o CRM em uma VM.

    b) PaaS, pois podem desenvolver um CRM próprio.

    c) SaaS, pois o software é fornecido pronto para uso.

    d) Nuvem comunitária, para compartilhar com parceiros.

    e) Nuvem privada, para maior segurança.

    Questão 5¶

    Um desenvolvedor criou uma aplicação web usando Django e deseja implantá-la sem se preocupar com provisionamento de servidores, balanceamento de carga ou escalabilidade. Ele quer apenas fazer upload do código e que a nuvem cuide do resto.

    Qual serviço AWS ele deve usar?

    a) Amazon EC2 com Auto Scaling

    b) AWS Lambda

    c) Amazon S3

    d) AWS Elastic Beanstalk

    e) Amazon Lightsail

    QUESTÕES DISCURSIVAS¶

    Contexto: Uma empresa de médio porte atua no setor de logística e possui um sistema de rastreamento de entregas desenvolvido internamente há 10 anos. O sistema roda em servidores físicos no data center da empresa, utiliza Java, banco de dados Oracle e requer configurações específicas de rede. A diretoria decidiu migrar para a nuvem para reduzir custos e aumentar a disponibilidade. A equipe de TI é experiente em administração de sistemas, mas não conhece profundamente as práticas de desenvolvimento para nuvem.

    Pergunta: Considerando os modelos de serviço em nuvem (IaaS, PaaS, SaaS), qual deles você recomendaria para essa migração? Justifique sua resposta analisando as vantagens e desvantagens de cada modelo no contexto apresentado. Discuta também como a escolha impacta a responsabilidade da equipe de TI e os custos operacionais.

    Contexto: Uma startup de educação online deseja criar uma plataforma para oferecer cursos interativos. A plataforma será desenvolvida do zero, com equipe de 5 desenvolvedores experientes em Python e Django. O prazo para lançamento é de 3 meses, e o orçamento inicial é limitado. Espera-se um crescimento rápido de usuários, podendo chegar a 100 mil acessos simultâneos em um ano.

    Pergunta: Compare os modelos IaaS e PaaS para este cenário. Qual deles é mais adequado para atender aos requisitos de desenvolvimento ágil, escalabilidade futura e baixo custo inicial? Detalhe como a escolha impacta o processo de desenvolvimento, a arquitetura da aplicação e as responsabilidades da equipe. Inclua na resposta uma sugestão de serviços AWS que poderiam ser utilizados e justifique.
